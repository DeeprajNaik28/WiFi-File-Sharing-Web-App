# WiFi-File-Sharing-Web-App

A modern peer-to-peer file sharing web application that allows users to transfer files directly between devices using WebRTC and Socket.IO. Users can connect through a simple QR code interface and share files instantly without storing them on a server.

Built using Node.js, Express.js, Socket.IO, and WebRTC.

---

# 🚀 Features

* 📱 Device discovery in real time
* 🔗 Direct peer-to-peer connection
* 📡 QR code website access
* 📂 File sharing between devices
* ⚡ WebRTC based transfer system
* 🎨 Modern responsive UI
* 🖱 Drag & drop file upload
* 📊 Upload progress bar
* ⚡ Transfer speed indicator
* 🌐 Deployable on Render

# ▶️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Open project folder:

```bash
cd wifi-share
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
node server.js
```

Open in browser:

```bash
http://localhost:3000
```

# 📸 How It Works

1. Open the website on multiple devices.
2. Enter device names.
3. Connect to another device.
4. Select or drag files.
5. Share files directly between devices.
